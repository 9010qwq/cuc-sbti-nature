# 私有活动统计 · 2.2.0

此目录提供可运行的 Node.js 24.15+ / SQLite 统计服务和受保护管理面板。现有网站继续放在 GitHub Pages，不需要迁移。**默认前端关闭采集；未配置真实 HTTPS 后端和运营者授权前，不会向统计服务发出请求。代码完成不等于已上线。**

## 当前接入条件

需要一个由运营者批准的、可运行 Node.js 24.15+ 且带持久磁盘的服务、一条 HTTPS 访问地址，以及仅保存在服务器上的管理员密码校验值。不是将 SQLite 文件放在 GitHub Pages，也不能放到每次部署都会清空的临时文件系统。

先确认服务商、费用/条款、数据保存地区和接收本活动统计的授权，再创建账号或部署。没有这些条件时只推送源码；不擅自注册、开通服务、生成生产凭证或启动第三方持续采集。已有服务器时本方案无新增 npm 后端依赖，使用 Node 内置 SQLite/crypto/http。Node 24 的 `node:sqlite` 仍有实验性标记，已在 24.15.0 验证；请固定运行时版本并备份数据库。[Node 24 SQLite 文档](https://nodejs.org/docs/latest-v24.x/api/sqlite.html)

## 最小部署步骤（取得上述授权后）

1. 将 `analytics/` 放到独立服务目录，数据库目录不属于网站公开目录。服务以独立非管理员系统用户运行，仅该用户可读写数据目录、服务器环境文件和密码校验值；文件权限应为600、目录700。设置进程 umask 077。不要提交 SQLite、运行环境文件或密码到仓库。
2. 由管理员在本地安全终端输入高强度密码，将 `passwordHash()` 生成的 `salt:scrypt-hash` 设置到服务器私有环境变量 `ANALYTICS_ADMIN_HASH`。不要把密码放命令行、前端、URL、构建变量或聊天里；不要回显凭据。登录用户名固定为 `admin`。服务端每次访问管理 HTML、JS、CSS、汇总 API 均校验 HTTP Basic；必须在 HTTPS 下使用。浏览器会缓存 Basic 登录，管理建议用私人窗口，结束后关闭窗口。多人管理/SSO可后续接入反向代理身份服务，不要公开共享账号。
3. 配置服务端变量（值中的示例地址必须替换）：

```text
ANALYTICS_MODE=production
ANALYTICS_DB=/private/sbti/events.sqlite
ANALYTICS_ORIGINS=https://9010qwq.github.io
ANALYTICS_PUBLIC_ORIGIN=https://stats.example.org
ANALYTICS_TRUST_PROXY=loopback
PORT=8788
# ANALYTICS_ADMIN_HASH 仅在服务器私有环境设置，不放本文件
```

4. 运行 `node analytics/server.mjs`，使用系统服务管理器维持进程。程序只监听127.0.0.1；用 HTTPS 反向代理转发到该端口，覆盖而非追加 `X-Forwarded-Proto` 和 `X-Real-IP`。禁止从外部直接访问 Node 端口。关闭该虚拟主机的访问日志和请求体/请求头调试日志；若云平台强制记录IP，需在上线前向用户说明供应商、保留政策，不能声称基础设施不处理IP。一个进程配一个SQLite库，不要使用多个互不共享存储的无状态实例。

参考 Nginx location（TLS证书、域名与系统服务由已有部署环境管理）：

```nginx
location / {
    access_log off;
    client_max_body_size 16k;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header Host $host;
    proxy_pass http://127.0.0.1:8788;
}
```

5. 私下访问 `https://stats.example.org/admin/` 验证登录；未认证访问 `/admin/api/summary` 必须返回401。管理界面无数据时显示“尚未收到事件”，不会伪装成活动0人。`/health` 仅返回服务状态和环境；不是前端联通证明。
6. 在**测试环境和独立测试数据库**验证完整点击与接收。确认接入、隐私文案及服务商授权后，构建前端时设 `VITE_ANALYTICS_URL=https://stats.example.org`（这是公开地址，不是密钥），再运行 `npm run build:web`。该 URL 必须是纯 HTTPS origin，不能带路径、密码、query。发布完整 `dist-web/` 到原 gh-pages，旧资产保留一段时间供仍打开旧页面的玩家使用，不强制刷新打断答题。
7. 线上用一次明确标记/隔离的验收环境先检查，确认真实用户选择同意后才在生产库收到真实事件。生产库严禁导入测试/演示样本；如果产生运营者验收事件，应在活动口径中披露，不要冒称玩家。后台没有填充假历史的脚本。

## 采集说明与口径

- 未配置URL时零统计请求、无统计标识创建；配置后仍须用户主动同意。支持随时关闭、删除本地统计标识，尊重 DNT / GPC。选择只影响这台浏览器；关闭不删除此前已入库的匿名记录，这些记录最多保留30天。若中途同意，仅下一次开始能形成完整测验批次，不回补之前事件。
- 浏览器随机标识存 localStorage，期限30天；页面会话每次打开重建，一次测验有独立 attempt ID。都不是账号或真实人数，禁用存储/清除存储/共用设备会影响估算。不使用指纹、位置、IP建档或跨站跟踪。
- 只发送固定枚举事件、随机ID、版本、粗设备类别、题序1–24、16型代码、卡片小类、两个彩蛋、修订号与耗时。时间由服务端接收时间决定；首次完成用时在服务端按15秒取整，只用于区间分析。当前真实小类只有卡片的“狂吃型探索者”标记，不额外发明角色分类。
- 不发送昵称、联系方式、活动署名、内容配置、逐题选项/答案、分数、自由文本、兴趣标签、页面URL/referrer、错误文本/堆栈或完整User-Agent。请求使用 `referrerPolicy:no-referrer`，不携带Cookie。网络服务仍必须处理连接地址；应用只用其短期HMAC值做一分钟限流，不落库、不记录日志。
- 页面打开只记录一次，不能在 render 中累计。题目首次到达按attempt+题号去重；完成按attempt去重。“修改回答”保留attempt并更新最新结果分布，不增加完成/开始次数。首次完成用时不被修订覆盖。线索①可能发生在开始前：按同会话记录，quiz_start的clue1布尔值保留其关联。重复点击线索不新增发现；奶蛙在unlock时、幼虫在首次“掰一半留着”时记录，重复查看不计解锁。
- 演示类型和彩蛋不发送完成、解锁或导出事件；页面打开本身仍可能来自工作人员。工作人员不是自动排除的真实人群，后台只区分测试数据库与生产库，不对“真实玩家人数”作保证。
- 开始批次漏斗按所选时段开始的attempt关联后续完成、预览、下载；跨日完成仍回到原批次。趋势/事件次数按入库时段统计，不能用同一天开始数和完成数直接相除。结果分布按该批次测验最新修订，故历史筛选结果会随后续修订变化。
- 未完成且30分钟无后续事件才推算超时，按最高到达题目列出；关闭/隐藏页面不直接算放弃。网络丢报、迟到事件也会影响推算，后来完成会改变统计。
- “下一位”或再次开始只能叫**同匿名浏览器重复测验**，不能认定是同一人重测。后台显示会话/浏览器去重和事件次数；不同维度的去重数不能简单相加。
- 保存按钮点击、PNG预览可解码、下载链接点击分别记录。无法证明系统保存成功。当前没有真实分享入口，后台明确显示“暂不可测”；不会把截图、下载、饼干分享剧情或系统长按算成社交分享成功。
- 首次入库、最后入库、查询时间和版本在面板展示。今天/此前的旧访问、旧2.1.0标签页、不同意或未送达的事件都无法回补。不要对历史填零冒充完整统计。

## 写入安全及边界

公开写入与私有读取完全分开。采集端要求明确Origin、JSON和短期签名会话令牌；令牌只能用于写入且一小时过期，服务重启会失效。前端不持有数据库密码、管理密码或长期写入密钥。匿名公开采集无法证明真人：攻击者可伪造Origin并申请会话，不能将此统计用于投票、奖品资格或精确人数结算。

服务端拒绝未知事件/字段、超范围数据、任意自由文本、超过16KiB请求和超过20条批次。参数化SQL、event_id及语义去重、每会话100批次/分钟、同出口1500请求/分钟、同出口150新会话/分钟和全局3000请求/分钟控制写入；校园共享出口50人不会被按“1个IP=1个人”计算。数据库上限20万事件、30天自动清理，达到上限返回503，不自动花钱扩容。后台查询最多31天，保留期外没有数据。统计是尽力送达：超时3秒、单批服务器错误最多重试一次且复用ID，内存队列上限80，不落离线队列。网络失败可丢统计，绝不阻塞答题或导出。

备份用 SQLite backup API/在线备份工具或停服务后完整备份库，不能只在WAL写入期间复制主文件。备份也含匿名数据，应有相同30天清理策略。按部署环境加HTTPS层限流/磁盘监控；这不是承诺抗大流量攻击的商业统计平台。
