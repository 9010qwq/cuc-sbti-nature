# SBTI · 自然界原形

**这里的 S，是 Science。** 为中国传媒大学自然科学社活动制作的原创娱乐测评。手机优先、可以截图、可以离线，也允许你最后发现自己是一块砖。

**欢迎关注微信公众号 CUC自然科学社**

## 直接玩

**[手机 / 电脑在线体验](https://9010qwq.github.io/cuc-sbti-nature/)** · [下载活动二维码](预览/SBTI手机扫码.png)

在线版无需下载文件，首次进入只加载当前页面的插画和需要的字体分片；所有答案仍在浏览器内计算。校园网与手机流量下的访问速度需在活动前实测。

在 GitHub Releases 下载「SBTI本地运行包.zip」，解压后双击「双击开始_SBTI自然界原形.html」。无需安装 Node、登录或联网。所有角色、字体和逻辑均在网页内；首次打开约31MB的本地文件，请给浏览器一点载入时间。

手机页面适配320—430像素窄屏及横屏。手机文件管理器、微信聊天中的HTML预览可能不执行网页程序；手机参与活动建议使用上方在线网址，离线HTML保留给支持本地网页的浏览器使用。

## 有什么

- 20道核心情境题，4道兴趣题，16种有内在组合逻辑的自然界原形。
- 16张独立切面角色插画，加1张奶蛙彩蛋插画；页面文字不烘焙进图片。
- 高清1080×1440 PNG结果卡、完整入镜的截图模式、手机长按保存预览。
- 四维解释、个人兴趣标签、图鉴、探索小任务、声音开关与减少动态效果。
- 工作人员演示、活动署名编辑、完整内容配置导入导出，以及下一位清场。

## 四维与16型

兴趣展开：广探B／深潜D；体验方式：上手H／观察O；同行偏好：结伴T／自游S；行动节奏：随兴F／筹划P。

| 代码 | 角色 | 代码 | 角色 |
|---|---|---|---|
| BHTF | 浣熊 TRY | DHTF | 蜜蜂 BUZZ |
| BHTP | 磁铁 LINK | DHTP | 砖头 BRICK |
| BHSF | 黑洞 EAT | DHSF | 蟑螂·赤石仙人 ROACH |
| BHSP | 乌鸦 KEEP | DHSP | 晶体 BUILD |
| BOTF | 灰喜鹊 BOMB | DOTF | 菌丝 THREAD |
| BOTP | 朱颈斑鸠 LEAD | DOTP | 鲸 DEEP |
| BOSF | 风滚草 WANDER | DOSF | 水豚 CHILL |
| BOSP | 星图 MAP | DOSP | 化石 FOREVER |

每维5题；各题四个选项为+2、+1、−1、−2。平分时追加一道该维度的二选一题。4道兴趣题独立记录，标签并列由参与者选择。昵称、时间与彩蛋不改变主类型；没有虚构的准确率、稀有度或能力排名。

这是原创娱乐分类，不是经验证的心理量表。角色行为属于幽默创作，不是物种百科；“朱颈斑鸠”为项目中保留的社团自称。蘑菇“尝一口”是明确标注的脑内弹幕，野外发现不要入口。

## 奶蛙在哪里

1. 首页点击物资箱底下露出的黄色脚，取得目击记录①。
2. 第10题后经过观察插页，点击移动的箱子，取得目击记录②。
3. 完成测评，在结果页点击“查看未登记访客”。奶蛙登场，结果卡加入“奶蛙目击者”贴纸。

任何主类型都能触发，与答题分数无关。工作人员面板可以直接演示；演示不会污染真实测评结果。点击“下一位”清空本次昵称、回答和目击记录。

## 现场使用

优先使用当前版本的 Edge / Chrome。先在活动设备上试走一遍完整流程，再交给参与者。声音默认关闭；手机与电脑均可使用。底部“工作人员”可改活动署名、导入导出内容配置、演示16型或奶蛙。内容配置保存在当前浏览器；导入会校验，失败不替换旧配置。参与者回答仅在当前页面会话中保留，刷新会重新开始。

## 开发与构建

需要 Node.js 24 或以上。首次安装开发依赖需要联网；生成的成品无需联网。

```sh
npm ci
npm run dev
npm run build
npm test
npm run test:browser
```

Windows浏览器测试默认使用已安装的Microsoft Edge。其他系统先执行 `npx playwright install chromium`；也可以通过 `SBTI_BROWSER_CHANNEL` 指定已安装的浏览器通道。

`src/data.ts`：题库、维度、类型文案与默认配置。`src/logic.ts`：纯计分、分流与配置校验。其余页面、卡片与样式放在 `src/`；独立PNG在 `assets/`；17份最终生成提示词在 `art-prompts/`。`prepare.mjs` 生成内嵌素材和字体，Vite构建后由 `pack.mjs` 生成单文件 `dist/index.html`。

需要发布网页版时，执行 `npm run build:web`，再执行 `npm run test:web` 验证。将生成的 `dist-web/` 整个目录发布到静态托管服务；图片和字体均使用相对路径，不依赖第三方CDN。当前GitHub Pages使用 `gh-pages` 分支的根目录，更新源码后需要重新构建并更新该分支。`main` 根目录的开发用 `index.html` 不能直接作为成品发布。

结果卡由真实文字与独立插画在Canvas绘制；等待字体与素材加载后才开放保存。配置中的公众号关注文案保持固定。没有应用后端、追踪器或账号系统；网页版的图片和字体从本站加载，离线版则全部内嵌。

## 验证范围

计分测试覆盖16型、平分分流、改答、兴趣并列与错误配置。浏览器测试使用隔离的无头Edge实际运行本地文件，检查离线答题、结果导出、窄屏与横屏、彩蛋和清场；不是只有DOM静态检查。全部角色和16张结果卡已人工式视觉审阅。

手机宽度验证属于浏览器模拟，尚未进行真实iPhone／Android设备以及活动现场真人试玩。具体检查记录见 `验证记录.md`。
