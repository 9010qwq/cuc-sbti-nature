## 功能

- 20 道核心情境题、4 道兴趣题、16 种自然界原形。题目使用具体生活场景，选项显示顺序混排。
- 保留浣熊；鼠王替换磁铁。奶蛙和新增的红黄双虫都作为独立彩蛋，不占主类型。
- 18 张独立 PNG 插画，以及构建时生成的 WebP 和 16 型图鉴总览；没有裁切提案板代替角色素材。
- 1080×1440 PNG 结果卡、截图模式、手机长按保存预览；两个彩蛋贴纸可以同时出现。
- 结果解读、兴趣标签、探索小任务和答题后开放的图鉴；声音默认关闭，可减少动态效果。
- 工作人员演示、活动署名编辑、配置导入导出，以及“下一位”清场。

首页的 S 使用绿色提示 Science；兴趣入口以三列两行排列。首次答题前的顶部只保留说明入口，声音设置放在页脚。更多变化见 [更新记录](CHANGELOG.md)。

## 四维与 16 型

兴趣展开：广探 B／深潜 D；体验方式：上手 H／观察 O；同行偏好：结伴 T／自游 S；探索步调：随兴 F／筹划 P。

| 代码 | 角色 | 代码 | 角色 |
|---|---|---|---|
| BHTF | 浣熊 TRY | DHTF | 蜜蜂 BUZZ |
| BHTP | 鼠王 RAT KING | DHTP | 砖头 BRICK |
| BHSF | 黑洞 EAT | DHSF | 蟑螂·赤石仙人 ROACH |
| BHSP | 乌鸦 KEEP | DHSP | 晶体 BUILD |
| BOTF | 灰喜鹊 BOMB | DOTF | 菌丝 THREAD |
| BOTP | 朱颈斑鸠 LEAD | DOTP | 鲸 DEEP |
| BOSF | 风滚草 WANDER | DOSF | 水豚 CHILL |
| BOSP | 星图 MAP | DOSP | 化石 FOREVER |

每维 5 题，每题只影响一个维度。内部四个选项依次对应 +2、+1、−1、−2，页面会改变它们的显示位置，计分含义不变。平分时追加一道对应维度的二选一题。4 道兴趣题只决定最多两个兴趣标签；边界并列时由参与者选择。

昵称、时间、彩蛋和显示顺序不改变主类型。选项混排用于减少“总点同一位置”的影响，不代表测评已获科学验证，也不保证各类型出现概率相同。这里不提供准确率、稀有度或能力排名。

这是娱乐分类，不是心理量表。角色笑点不是物种百科；“朱颈斑鸠”保留社团自称。蘑菇“尝一口”是脑内弹幕，野外发现不要入口。

## 两个彩蛋

**奶蛙：**

1. 首页点击物资箱底下露出的黄色脚，取得目击记录①。
2. 第 10 题后的观察插页中，点击移动的箱子，取得目击记录②。
3. 完成测评，在结果页点击“查看未登记访客”，获得“奶蛙目击者”贴纸。

**红黄双虫：**在结果页点击“掉落的饼干”，再选择“掰一半留着”，获得“快乐搭子”贴纸。

任何主类型都可解锁，两条彩蛋线彼此独立，可以同时保留。工作人员面板可单独演示，演示不会改变真实结果或目击进度。“下一位”清除昵称、回答、结果和两个彩蛋的进度。

## 现场使用与配置

先在活动设备上完成一次答题、截图和图片保存。结果页“截图模式”将整张卡缩进可视区域，轻触或按 Esc 退出；“保存图片”生成高清 PNG，手机也可在预览图上长按保存。

页脚“工作人员”可修改活动署名、演示角色和彩蛋、导入或导出完整内容配置。导入成功会清空本次答题，请在两位参与者之间操作。公众号关注文案固定保留。

2.1 沿用 2.x 配置格式 `version: 2` 和浏览器存储键 `sbti-content-v2`，兼容 2.0 配置。1.0 配置不能直接导入；请先导出一份当前配置，再按需要重新编辑。导入失败会显示原因并保留当前配置。

工作人员设置只影响这台设备的当前浏览器，不会同步给其他人。统一更新线上内容需要重新构建并发布网站。逐题答案不持久保存，也不会由应用上传；启用并同意统计时会发送最小化的事件与结果类型，详见统计说明；刷新后重新开始。设备偏好和活动配置可保存在当前浏览器。

## 开发与构建

需要 Node.js 24 或以上。首次安装开发依赖需要联网，离线成品运行不需要。

```sh
npm ci
npm run dev
npm run build
npm test
npm run test:browser
```

Windows 浏览器测试默认使用已安装的 Microsoft Edge。其他系统可先执行 `npx playwright install chromium`；也可通过 `SBTI_BROWSER_CHANNEL` 指定已安装的浏览器通道。

| 位置 | 用途 |
|---|---|
| `src/data.ts` | 题库、维度、角色文案与默认配置 |
| `src/logic.ts` | 计分、平分处理、兴趣标签及配置校验 |
| `src/main.ts`、`src/style.css` | 页面交互和响应式排版 |
| `src/card.ts` | 使用真实文字与角色图绘制结果卡 |
| `assets/`、`art-prompts/` | 独立 PNG 与生成提示词 |
| `prepare.mjs` | 生成 WebP、16 型总览以及构建所需图片和字体资源 |
| `pack.mjs`、`pack-web.mjs` | 分别产出离线单文件和静态网页版 |

`npm run build` 生成可离线打开的 `dist/index.html`。`npm run build:web` 生成 `dist-web/`，随后可运行 `npm run test:web` 检查。网页版必须发布完整目录，图片和字体采用相对路径，从同站加载。详见 [网页版发布说明](网页版发布说明.md)。

结果卡等待图片与字体就绪后再开放保存。默认关闭统计时没有采集请求；答题不需要后端或账号。可选统计后端与答题功能分离，统计失效不影响答题。

## 验证范围

2.1 发布时检查包括 27 项逻辑、109 项文案匹配、114 项离线浏览器与 37 项网页子路径回归，涵盖 16 型、平分、回退改答、配置错误、两个彩蛋、清场、窄屏与横屏、截图及 PNG 保存。2.2 继续通过逻辑/文案、37项网页回归，并增加统计服务及采集浏览器验证；运行命令与边界见 [统计说明](analytics/README.md)。

本地网页测试中，首页请求 3 张角色图，响应体总计 807,808 字节，约 789 KiB。该数值是本次构建和测试条件下的结果，不是固定打开时间。

浏览器检查使用隔离的 Edge 实际运行，手机宽度属于模拟；尚未完成真实 iPhone／Android、微信内置浏览器或活动现场真人试玩。验证范围与本次更新说明见 [SBTI 2.1 Release](https://github.com/9010qwq/cuc-sbti-nature/releases/tag/v2.1.0)。
